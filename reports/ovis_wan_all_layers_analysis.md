# OVIS × Wan2.1 全层 Attention Head 功能分析

**生成日期：2026-09-05**  
**扫描范围：30 layers × 12 heads × QK/KK = 720 个 layer-head-mode 结果**  
**数据：OVIS validation，140 个视频 / 8,784 帧 / 815 个实例轨迹 / 25 个类别**  
**每个 layer-head-mode：29,633 个 query-target 样本；P/I 指标覆盖 140 个视频，G 指标覆盖 136 个视频**

> **核心结论：** 类别语义功能主要集中在中层，最可信的跨 QK/KK 候选是 **L15H7、L13H10、L12H1、L16H10、L10H2、L17H9**；位置功能在末层强烈增强，最明确的是 **L28H11**，其次为 **L29H9、L27H11、L28H8**。OVIS 没有点级真实对应区域 C，因此本报告不能单独判定 matching head，matching 仍需 TAP-Vid 结果。

## 1. 报告目标与边界

- 本报告分析的是 **semantic head** 与 **position head**，并给出每个 `(layer, head)` 的连续功能画像，不强迫所有 head 只能属于一个类别。
- OVIS 提供跨帧实例 mask 与类别 ID，可以构造 P/I/G/O；但不提供 query 点在目标帧的精确对应点，因此没有 C。
- 因此，**高 I/G 只能证明对象或类别语义响应，高 P 证明原坐标偏置；matching 必须结合 TAP-Vid 的对应点与跟踪指标判断。**
- 固定方法定义见 [`docs/head_function_identification.md`](../docs/head_function_identification.md)。本文没有修改该基线定义，只报告 OVIS 可计算部分。

## 3. 两套相似度图如何计算

设源帧 query patch 为 `q`，目标帧候选 patch 为 `i`，head 维度为 $d_h=128$。

### 3.1 Q-K：模型原生 attention 行为

$$z_{QK}(i)=\frac{Q_h(q)^\top K_h(i)}{\sqrt{d_h}}$$

QK 最接近该 head 在模型内部实际使用的注意力 logit。

### 3.2 K-K：Key descriptor 的可匹配性

$$z_{KK}(i)=\cos(K_h(q),K_h(i))$$

KK 衡量 Key 表征自身是否形成可复用的对象/语义 descriptor。QK 与 KK 数值尺度不同，**只能分别排名，不能直接比较绝对值大小**。

### 3.3 Attention 概率

$$p(i)=\operatorname{softmax}(z(i)/\tau),\qquad \tau=1$$

Mass、Density、Lift 使用 $p(i)$；DeltaZ、Coverage、Top1 使用原始 $z(i)$。

## 4. OVIS 中的 P / I / G / O 区域

| 区域 | 当前实现 | 功能含义 |
|---|---|---|
| P：Position | 目标帧中，以源 query 旧坐标为中心、半径 1 patch 的圆盘 | 检查 head 是否仍盯着原空间位置 |
| I：Instance | 目标帧同一实例 mask，排除 P | 检查同一具体物体的非局部响应 |
| G：Category | 目标帧同类别、不同实例 mask，排除 P 和 I | 检查是否泛化到其他同类实例 |
| O：Other | 除 P/I/G 外的其余 patch | 作为负样本与归一化基线 |

区域按 `P → I → G → O` 的优先级构造，彼此互斥。因为没有 C，本实验中的 P 没有再减去真实对应点区域。

| `other_density` | O | $\sum_{i\in O}p(i)/\lvert O\rvert$ | 诊断 | O 区单位 patch softmax 密度；Lift 的分母基线，无固定优劣方向。 |

### 5.1 指标使用优先级

1. **主指标：Lift。** 它先按区域面积归一化，再相对 O 做比值，最适合跨区域比较。
2. **Coverage：** 判断响应是否覆盖一片区域，避免把单个异常峰误当成语义。
3. **Top1：** 判断最强峰落在哪里，适合位置/匹配式尖峰，但不能单独识别宽响应 semantic head。
4. **DeltaZ：** 不依赖 softmax，但 QK 的绝对尺度受 Q/K norm 影响，跨 head 单独排序可能误导。
5. **Mass：** 直观但受区域面积影响，不能脱离 Density/Lift 使用。
6. **O 指标：** 只作为背景基线诊断，不是功能得分。

## 6. 跨视频聚合与稳定性字段

| 字段 | 含义 |
|---|---|
| `mean` | 视频等权后的数据集均值 |
| `median` | 跨视频中位数 |
| `q25`, `q75` | 跨视频四分位区间 |
| `videos` | 对该指标提供有效样本的视频数 |
| `top20_video_fraction` | 该 head 在多少比例的视频中进入**本层同 mode 的前 20%** |

重要细节：每个 layer 报告只比较该层 12 个 heads，因此 `ceil(12×20%) = 3`。合并后保留的 `top20_video_fraction` 实际是“**层内 Top-3 视频占比**”，不是 360 个 layer-head 的全局 Top-20%。跨层结论应主要看 mean/median/IQR。

### 7.1 对 20 个指标的结果解释

- **P/Mass、P/Density、P/Lift：** 三者都把 L28H11、L29H9、L27H11、L28H8 推到最前，说明末层存在非常明确的旧坐标注意力。QK 的 top position heads 甚至把约 98%–99% 的概率压到很小的 P 区域。
- **P/Coverage 与 Top1-P：** 很多早层 head 已达到 1.0，说明它们能产生原位置峰，但这两个指标在顶部发生饱和；用于区分最强位置 head 时，Lift、Mass、Density 更有分辨力。
- **I/Lift：** 中层语义 head 很强，但只看 I 会把 L15H1、L28H11、L28H8、L29H9 等位置/局部结构 head 排得很高。I 必须与 P 和 G 联合判断。
- **I/Coverage 与 Top1-I：** L11–L16 的多组 head 稳定靠前，说明这些层的对象响应不只是单点峰，而是覆盖同一实例。
- **G/Lift：** 是本实验最重要的类别语义指标。QK 最高为 L15H7，KK 最高为 L13H10；二者在另一模式也都处于全局前列。
- **G/Coverage：** L11H10、L15H7、L13H10、L12H1 等中层 head 靠前，进一步证明高 G-Lift 不是少数 patch 拉高。
- **Top1-G：** 早层 L4H9/L5H3 也可很高，但这更像“峰值偶尔落到同类实例”，不能替代 G-Lift 与 G-Coverage 的宽响应证据。
- **DeltaZ：** KK 的 G-DeltaZ 与 G-Lift 基本一致；QK 的 G/I-DeltaZ 被 L28H11 等超大 logit 范数显著影响，证明 QK DeltaZ 不应单独跨 head 排名。
- **O mean/density：** 仅描述背景基线。O-density 大会压低 Lift，O-mean 大反映整体 logit 偏置，二者都不应直接称为“好 head”。

## 13. 最终结论

1. **Pipeline 已经形成完整的全层功能图谱。** 30×12 个 heads 在 QK/KK 两套空间、20 个指标上均有结果，且每个候选使用同一批 29,633 个 query-target 样本。
2. **语义不是均匀分布，而是集中在中层。** L10–L18 是主语义带，L13/L15 最集中；L22–L25 形成次级语义峰。
3. **最可信 category-semantic heads：** L15H7、L13H10、L12H1、L16H10、L10H2、L17H9。若只选一个用于后续可视化/干预，优先 L15H7；若希望 QK/KK 都非常强且对象响应完整，L13H10 也应并列重点检查。
4. **最可信 position heads：** L28H11、L29H9、L27H11、L28H8。L28H11 的 QK P-Lift = 22.5370、P-Mass = 0.9869，是最明确的旧坐标锁定 head。
5. **Instance semantic 不能只看 I-Lift。** L15H1 和末层位置 heads 会因位置/局部结构获得高 I；必须联合 P、G、Coverage 与 QK/KK 一致性。
6. **QK 与 KK 对类别语义的排序高度一致。** G-Lift Spearman ρ 约 0.893，G-Coverage 约 0.939，说明发现并非只存在于某一种相似度定义。
7. **L15H2 不应被这份 OVIS 报告改名为纯 semantic head。** 它更适合作为 TAP-Vid 已验证的 matching head，并保留一定 QK semantic 信号；最终标签应为多维画像而非唯一类别。
8. **本报告不能完成 matching head 的自动发现。** 下一步如果要把三类 head 放在同一张图里，必须把 TAP-Vid 的 C/MatchLift/Top1Hit/PointError 与这里的 P/I/G 指标按相同 `(layer, head)` 合并。
